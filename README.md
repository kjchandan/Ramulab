# Ramu Lab Website

Responsive static website for Ramu Lab at the Regional Centre for Biotechnology. It presents lab research, team members, projects, patents, publications, alumni, gallery, and contact information.

## Project contents

- `index.html` is the website entry point.
- `css/` and `js/` contain the site styles, interactions, and required Bootstrap/AOS libraries.
- `img/lab/` contains the lab photographs used by the site.
- `webfonts/` contains the Font Awesome solid and brand WOFF2 fonts used by the interface.
- `lab-profile-reference.pdf` is the supplied lab profile reference.

## Preview and deployment

Open `index.html` directly for a local preview. The site has no build step. To use GitHub Pages, publish this repository from its root using the main branch.

## Before publishing

Verify the contact details and research information with the lab. Social-profile icons are placeholders until verified profile URLs are supplied.
